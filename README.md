# Тестовое задание 
API для управления тасками.
1. Пользователь добавляет токен
2. Авторизация админа
3. Авторизированный админ может посмотреть все таски
4. Авторизированный админ может дать ответ на таск
## Разработка

Запуск очереди
```bash
php yii queue/listen --verbose=1 --color=0
```

Сгенерировать openApi
```bash
php yii swagger/generate
```

Документация
```php
http://0.0.0.0:8080/swagger/
```
